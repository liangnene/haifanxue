## 项目经历 Project Experience

### 海翻学 ── AI 翻译与学习笔记工具  `主项目`  ｜  2024.06 - 至今

**项目背景**：面向海外华人 / 赴日工作华人，把日语教材（宅建士、行政书士、税理士等考试用书）拆解为中文翻译、考点卡片和可追问的对话。需求源于上一段自媒体咨询业务中识别出的高频痛点：用户面对大部头日语原版教材时，传统人工扫描翻译 PDF 效率极低、缺乏结构化学习路径、遇到具体考点无法即时追问。项目以「大部头教材，不必硬啃」为产品主张，独立完成从需求洞察、产品架构、UI/交互设计到 Web Demo 落地的全流程。

**核心职责**：

1. **需求洞察与场景拆解**
  - 基于 2024.06 至今积累的 300+ 真实咨询用户行为数据，把「啃教材」这一笼统痛点拆解为四类可被 AI 解决的子场景：原文翻译、考点抽取、易错点对话追问、考试题预测。
  - 输出用户画像、典型学习路径、核心使用场景的产品需求文档，明确 MVP 阶段优先保留「对话 + 翻译资料 + 考点卡片」三大模块，砍掉了「视频课」「社区」等重资产路径。
2. **AI 能力产品化设计**
  - 对话模块：设计大输入框 + 文件上传 + 示例提问的入口，承接「先把文件丢进来 → 再开始问问题」的真实学习行为；接入 DeepSeek / OpenAI 双模型，并在 UI 层提供模型切换，让用户在响应速度与回答质量之间自助权衡。
  - 翻译资料模块：把传统「整本扫描 PDF 翻译」的重操作，重构为「上传 PDF / 图片 / txt → 自动分段 → 段落级中日对照 + 术语注解」的轻流程，目标是把单份教材资料的处理时间从约 30 分钟人工翻译压缩到 1 分钟级 AI 输出，效率提升约 500%。
  - 考点卡片模块：定义「概念 / 定义 / 易错点 / 可能考题」四段式结构化输出标准，让 AI 不只是"回答问题"，而是产出可被学习者沉淀、复用的知识资产，区别于通用聊天产品。
3. **用户体验与交互设计**
  - 面向海外华人 / 中高龄考级用户的使用习惯，定调"日式工具风"：米白底 + 靛蓝 #3B5BDB 强调色、仅中文界面、克制的视觉密度，避免主流 AI 产品常见的"赛博朋克 / 极客感"对目标用户的心理门槛。
  - 设计左侧功能栏 + 中央对话区的工作台布局，确保用户进入后第一屏即明确"这是一个干活的工具"而非"一个聊天机器人"。
  - 落地新手引导：首次登录自动弹三步介绍、侧边栏可手动重开，把"这个产品能帮你做什么"压缩到 30 秒内说清楚，降低 35+ 用户的学习成本。
4. **MVP 链路与商业化设计**
  - 以注册 / 登录 / 退出 + 工作台 + 模型切换的最小可用闭环作为 MVP 范围，配合 localStorage 假鉴权快速验证主链路，避免在 MVP 阶段陷入用户系统建设。
  - 设计商业化路径：免费翻译与基础问答引流，高频深度问题转化为付费咨询、资料深度翻译、考级路径规划等服务，已在自媒体侧验证累计付费用户 1000+、客单价约 300 元的转化模型。
  - 规划下一阶段：接入真实模型的流式输出、PDF / 图片 / txt 多格式解析、对话历史持久化，并复用现有付费用户作为种子，验证从自媒体咨询到产品化付费的迁移效率。

**项目成果**：

- 独立完成产品需求文档、UI 设计、Web Demo 三大产出，项目可作为面试演示稳定运行
- 教材资料处理效率较传统人工 PDF 翻译提升约 500%（半小时 → 1 分钟级）
- 同期自媒体侧累计验证付费用户 1000+、客单价约 300 元，跑通「AI 问答引流 → 付费深度服务」的商业化路径
- 形成可复用的"AI 学习工具"产品方法论，覆盖需求洞察 → AI 能力封装 → 交互设计 → 商业化的完整链路
